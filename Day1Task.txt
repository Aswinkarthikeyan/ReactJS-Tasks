1. JAVASCRIPT


JavaScript is a high-level, dynamically typed programming
language used to add logic, behaviour and interactivity
to applications.

It manages data through variables, data types, operators,
functions and scope while following defined syntax and
statements during execution.

It interacts with web pages through the DOM and supports
browser-based data handling using storage, cookies, and cache.

HTML        -> Structure
CSS         -> Styling
JavaScript  -> Logic / Behaviour


2. MEMORY

Stack:
-> Stores execution-related data
-> Function calls
-> Local variables

Heap:

3. EXECUTION

5. VARIABLES

10. SCOPE

Scope means the area where a variable can be accessed.

Types of Scope:

1. Global Scope
2. Function Scope
3. Block Scope




## Global Scope

A variable declared outside functions or blocks
can have global scope.


let globalVariable = "Global";
// STATEMENT

function showGlobal() {
// FUNCTION DECLARATION -> STATEMENT


console.log(globalVariable);
// console.log(globalVariable) -> EXPRESSION
// Entire line -> EXPRESSION STATEMENT


}



## Function Scope

Variables declared using var inside a function
are available within that function.


function exampleFunction() {
// FUNCTION DECLARATION -> STATEMENT


var functionVariable = "Function Scope";
// STATEMENT

console.log(functionVariable);
// EXPRESSION STATEMENT


}



## Block Scope

Variables declared using let and const inside {}
are available only inside that block.


if (true) {
// true -> EXPRESSION
// if block -> STATEMENT


let blockVariable = "Block Scope";
// STATEMENT

const blockValue = 100;
// STATEMENT

console.log(blockVariable);
// EXPRESSION STATEMENT

console.log(blockValue);
// EXPRESSION STATEMENT


}


IMPORTANT:

var   -> Function Scope
let   -> Block Scope
const -> Block Scope

13. TYPE CONVERSION

Type conversion means changing a value from one
data type to another.

Types:

1. Explicit Type Conversion
2. Implicit Type Conversion




## Explicit Conversion

The programmer manually converts the data type.


let stringAge = "23";
// STATEMENT

let numberAge = Number(stringAge);
// Entire line -> STATEMENT
// Number(stringAge) -> EXPRESSION
// Function call expression

let textNumber = String(100);
// Entire line -> STATEMENT
// String(100) -> EXPRESSION

let booleanValue = Boolean(1);
// Entire line -> STATEMENT
// Boolean(1) -> EXPRESSION



## Implicit Conversion

JavaScript automatically converts the data type
during certain operations.

This is also called Type Coercion.


let value1 = "10" + 5;
// Entire line -> STATEMENT
// "10" + 5 -> EXPRESSION

let value2 = "10" - 5;
// Entire line -> STATEMENT
// "10" - 5 -> EXPRESSION

A function can:

* Return output

## Function Declaration

return a + b;

Function Call

15. FUNCTION EXPRESSION

This is called a Function Expression.


const greet = function () {

};



16. ARROW FUNCTION

Arrow function is a shorter way of writing a function.


const add = (a, b) => {
// Entire line -> part of a VARIABLE DECLARATION STATEMENT
// (a, b) => {...} -> ARROW FUNCTION EXPRESSION


return a + b;
// STATEMENT
// a + b -> EXPRESSION


};


Short form:

const add = (a, b) => a + b;

Entire line
-> STATEMENT

(a, b) => a + b
-> ARROW FUNCTION EXPRESSION

a + b
-> EXPRESSION
